Software Services

BdREN eFile

BdREN has developed eFile, a sophisticated electronic office file management system designed to streamline the process of file note approvals eliminating the need for manual document handling and approval processes. BdREN has further enhanced the eFile system with the development of the Approval Management System (AMS), which extends eFile’s functionality by providing a more comprehensive solution for managing approvals and decision-making across various organizational levels.

Finance Management System (FMS)

The Finance Management System (FMS) is a comprehensive software solution designed to simplify and automate financial and accounting operations. Suitable for both educational institutions and businesses, FMS ensures accuracy, efficiency, and real-time financial oversight.

Key Functionalities:

  1. Real-Time Financial Tracking
  2. Automated Invoicing
  3. Budget Management
  4. Financial Reporting
  5. Intuitive Dashboards
  6. Secure Data Management
  7. Expense Tracking

HRMS

The Human Resource Management System (HRMS) is an integrated software solution designed to streamline and optimize all aspects of human resource management. Tailored for organizations of all sizes, HRMS offers a centralized platform to manage employee data, payroll, recruitment, performance, and more. With its user-friendly interface and powerful features, HRMS helps organizations enhance operational efficiency, ensure compliance, and improve overall employee satisfaction.

Graduate Record Issuance & Verification System

BdREN has developed the Graduate Record Issuance and Verification System (GRIVS), an innovative solution designed to streamline the process of issuing, verifying, and validating academic certificates. GRIVS ensures the secure and automated issuance of graduate certificates with built-in verification features, providing a reliable, transparent, and tamper-proof system for both graduates and employers.

The system leverages modern technology to generate encrypted QR codes that link directly to the graduate’s certificate, enabling real-time verification and reducing the chances of certificate fraud.

Developing Website for BRUR

"BDREN successfully developed the new web portal for Begum Rokeya University, Rangpur (BRUR), accessible at https://brur.ac.bd/. BRUR and BDREN signed an MoU on April 29, 2024, to provide this service. The portal offers a user-friendly experience, allowing students, faculty, and visitors to easily access essential information and resources. BRUR has enthusiastically accepted the new platform, which aligns with their vision for digital transformation. BDREN has also provided training to the faculty members and administrative staff of BRUR on usage of the portal and its administration.

FileSender: Secure File Sharing Solution

BdREN developed FileSender, accessible at https://apacfilesender.asia/en/login, is a secure and user-friendly platform designed to facilitate large file transfers across educational and research networks. Built with the needs of researchers, educators, and institutional staff in mind, FileSender ensures data integrity, security, and efficiency in file sharing.

Orbit - Event Management System

BdREN’s Event Management System (EMS) named Orbit is a dynamic platform designed to streamline the planning, organization, and execution of events for educational institutions, research communities, and professional organizations. Whether it's conferences, webinars, workshops, or training programs, EMS provides an end-to-end solution for managing all aspects of events with ease.

 

University Management System (UMS)

BdREN's University Management System (UMS) is a comprehensive, web-based solution tailored to meet the diverse operational and administrative needs of universities. The UMS streamlines processes ranging from student admissions to academic management, empowering educational institutions to operate efficiently and deliver an enhanced learning experience.

Key Features of UMS:

  1. Student Admission Management
  2. Academic and Curriculum Management
  3. Student Records Management
  4. Fee and Financial Management
  5. Examination and Result Processing
  6. Communication and Notifications
  7. Hostel and Transportation Management
  8. Library Management System

 

BeLISAC Zoom Dashboard

The BeLISAC Zoom Dashboard, accessible at https://dashboard.belisac.bdren.net.bd/bdren/, is a specialized platform developed by BdREN to provide real-time monitoring, management, and analytics for Zoom-based communications within BdREN (Bangladesh), LEARN (Sri Lanka), NREN (Nepal), DrukREN (Bhutan) and LERNET (Laos). Designed for educational and research institutions, the dashboard offers comprehensive insights into virtual meeting activities, enabling administrators to optimize resources, ensure compliance, and enhance the overall user experience.
Key Features:

  1. Real-Time Monitoring
  2. Usage Analytics
  3. Dashboard Customization
  4. User Management
  5. Secure Access

vSession: Zoom Scheduler by BdREN

vSession is a powerful scheduling tool developed by BdREN, designed to facilitate the seamless integration of Zoom video conferencing with efficient scheduling capabilities. Aimed at simplifying the process of managing Zoom meetings, vSession provides users with a user-friendly interface to schedule, manage, and customize Zoom sessions for various academic, organizational, and professional needs.

Available at https://vsession.bdren.net.bd/login vSession is an essential tool for institutions, businesses, and organizations that rely on Zoom for virtual meetings, classes, webinars, and collaborative sessions.

Learning Management System (LMS)

A Learning Management System (LMS) is a comprehensive platform that enables organizations to manage, deliver, and track educational content and training programs. It provides a centralized system for instructors and learners to interact, access learning materials, track progress, and engage with various resources. BdREN offers customized Moodle LMS solutions tailored to the specific needs of institutions and organizations, ensuring that they can deliver a seamless and interactive learning experience.

 

Key Features and Functionalities:

  1. Course Management
  2. User Enrollment and Access Control
  3. Interactive Content Delivery
  4. Progress Tracking and Reporting
  5. Certification and Badging
  6. Discussion Forums and Collaboration
  7. Mobile Access

TEIN Compendium

BdREN’s TEIN Compendium is a centralized platform designed to streamline the management, sharing, and collaboration of information for the Trans-Eurasia Information Network (TEIN) community. This compendium serves as a robust repository for Asia-Pacific NREN activities, enabling seamless coordination and knowledge sharing among partner organizations.

 

Key Features of the TEIN Compendium:

  1. Centralized Information Repository
  2. User Authentication and Secure Login
  3. Project and Activity Tracking
  4. Interactive Dashboard
  5. Collaboration Tools
  6. Customizable Reports

NREN Maturity Calculator

BdREN’s NREN Maturity Calculator, available at https://mc.bdren.net.bd, is a specialized tool designed to help National Research and Education Networks (NRENs) evaluate their level of operational maturity. By assessing key performance indicators and functional domains, the calculator provides actionable insights to guide strategic improvements and enhance the services offered by NRENs to their respective education and research communities.

 

Key Features of the NREN Maturity Calculator:

  • Comprehensive Assessment Framework
  • Customizable Evaluation
  • Interactive Scoring System
  • Visual Analytics and Reports
  • User-Friendly Interface
  • Progress Tracking

BdREN Single Sign-On (SSO)

The BdREN Single Sign-On (SSO) platform, accessible at https://accounts.bdren.net.bd, is a unified authentication solution that enables seamless access to multiple BdREN services with a single set of credentials. This system enhances user convenience, security, and efficiency by eliminating the need for multiple logins across platforms.

 

Key Features:

  1. Unified Access
  2. Secure Authentication
  3. Customizable User Roles
  4. Integration with Institutional Systems
  5. Scalability
  6. Multi-Factor Authentication (MFA)

BdREN Task Management System

This system is built to enhance productivity, ensure accountability, and simplify the management of tasks for projects of all scales.

 

Key Features:

  2. Project Management Tools
